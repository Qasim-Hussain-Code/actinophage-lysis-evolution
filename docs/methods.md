# Methods

This document describes the implemented analysis and its configured defaults. Cohort sizes, exclusions and biological-control recovery are documented separately for the [original pilot](results.md) and the [expanded exploratory screen](exploratory_screen_results.md). Deposited annotation, independent reference homology and evolutionary interpretation remain distinct.

## Software and execution settings

The analysis uses Python 3.14.4 and MMseqs2 release 18-8cc5c. `requirements.txt` pins Biopython 1.86, NumPy 2.3.4, pandas 2.3.3, SciPy 1.16.3, statsmodels 0.14.6, Matplotlib 3.10.7, PyYAML 6.0.3 and pytest 9.0.2. MMseqs2 uses four threads, a five-residue prefilter seed and a 1G split-memory setting. These are algorithm settings rather than a bound on total process memory.

Primary functional assignments use pairwise homology. The exploratory remote-LysB diagnostic uses FAMSA and profile HMMs, with dependencies pinned in `requirements-profile.txt`. Profile candidates remain separate from primary assignments. Independent gene calling, transmembrane prediction, Phold and Phynteny are not part of this workflow.

## Acquisition and deterministic selection

The acquisition stage requests PhagesDB's official sequenced-phage TSV export at `https://phagesdb.org/data/?set=seq&type=full`, then verifies completion flags locally. Selection uses that export rather than an API sequenced-only filter. The workflow retrieves metadata before selected genome sequences. It normalizes host, host genus, cluster, subcluster, accession and end-type evidence. The source export and accessioned GenBank records remain untracked locally. [Source and reuse details](data_provenance.md).

Eligible rows belong to Mycobacterium or Gordonia, have a completed sequence flag and an accession matching the implemented accession syntax. Required controls D29 and Yvonnetastic are selected first. Remaining candidates are grouped by host genus and cluster, with missing clusters and singletons kept separate by phage name. A SHA-256 ranking of seed 20261016 plus phage or cluster name fixes the order independently of lysis outcomes. Groups having at least two eligible genomes are prioritized, genera alternate, and the first pass considers the first two ranked members of each group. Additional rounds consider one further ranked member per group until the requested target is reached. Accessions are deduplicated by base accession; insufficient unique eligible records raise an error rather than silently underfilling the target. Requested mode sizes are 20, 50 and 300. The 50-record exploratory cohort preserves the exact 20-record pilot prefix and has been completed under its [separate stages 1–5 protocol](exploratory_screen_protocol.md). The normal nine-stage expansion remains gated on completed pilot validation and a supported separated candidate; increasing the requested sample size does not bypass that gate. The 300-genome analysis has not been run.

NCBI EFetch retrieves each selected GenBank record. The returned accession must match the requested base accession and include a sequence version. The stage renames the file to that accession version and freezes its checksum, URL, retrieval time and metadata in a mode-specific manifest. Reuse checks frozen file checksums. Offline mode requires the cached metadata, manifest and source files; it does not resolve missing inputs remotely. Downloads use bounded streaming, temporary files, three attempts and replacement only after completion.

## Genome and CDS quality control

A record must contain 10,000 to 500,000 bases, use permitted IUPAC nucleotide symbols, have at most 1% ambiguous bases, identify a phage in its description, explicitly state complete genome or complete sequence, and contain CDS annotations. Each CDS part must lie inside the genome. All coordinates are retained as zero-based, half-open intervals, with compound-location parts, strand, gene label, locus tag, product, feature notes, deposited protein accession and translation status.

Translations are recalculated using the feature's genetic code and codon-start offset. Valid alternative initiation codons can account for an initial methionine. A translation mismatch excludes the genome. Missing translations, pseudogenes, incomplete codons, unresolved translation exceptions and fuzzy coordinates mark a CDS as partial or unsuitable for primary protein analysis. Only translated, nonpartial CDS enter the searchable proteome.

Exact duplicate screening hashes the lexicographically smaller of the sequence and its reverse complement. This is orientation invariant but not invariant to arbitrary circular rotation. Potential near duplicates are screened with the bottom 1,000 hashes of canonical 21-mers; sketch Jaccard of at least 0.95 joins connected screening groups. The lexicographically first accession is the representative. This proxy is not ANI, a phylogeny or a guarantee of independence.

## Functional evidence

`references/protein_controls.tsv` records literature-supported lysis proteins and D29 gp17, identified experimentally in a virion protein band, as a structural specificity control. It is not experimental proof that gp17 lacks every possible secondary function. Reference CDS are resolved from their source records by protein accession or an explicitly curated gene label. A separate manifest records resolved versions and source and protein SHA-256 values. Replay requests the pinned source version and verifies the freeze. Ms6 AF319619 is used only as a lysis-locus reference; it is not treated as an eligible complete Ms6 genome.

MMseqs2 `easy-search` compares study proteins to the reference set with sensitivity 7.5, k-mer length 5, alignment mode 3, E-value limit 0.001, candidate identity 0.25, coverage 0.5, coverage mode 0 and at most 100 target hits. Evidence filtering is stricter: moderate confidence requires identity at least 0.40, query coverage at least 0.70, target coverage at least 0.70 and E-value at most 1e-6. The original panel transfers support from experimental references. In the expanded 39-reference panel, published profile predictions can also support moderate A/B assignments; generic lipolytic and antimycobacterial assays can support moderate B assignments. These three evidence tiers are capped at moderate, including exact matches. Other nonexperimental reference evidence remains low. High confidence requires an eligible experimental reference plus identity and both coverages at least 0.999999. Thus high confidence has an exact-reference operational meaning in this implementation, not a general claim of validated homology. Partial CDS are downgraded to low confidence. [Reference tiers and evaluation](lysterase_update_results.md).

For each protein and functional category, the best supported confidence tier is prioritized before E-value, bitscore and reference identifier. This prevents a partial match from suppressing a qualifying full-coverage reference. Negative-control matches are saved separately and never propagate a lysis label. GenBank product labels and feature notes provide annotation-only low-confidence evidence, with the original note retained. A deposited holin label is called holin-like unless independent reference evidence supports holin. No neighborhood information upgrades a function. The primary architecture set accepts high and moderate assignments; high-only and annotation-only analyses remain distinct.

## Architecture

Architecture reconstruction retains every eligible Lysin A and Lysin B pair in high-only, high/moderate and annotation-only scopes. The principal intervening-CDS count is the absolute difference between validated genomic-order CDS indices minus one on linear records. Genes that overlap an anchor boundary still count as intervening when their CDS order lies between the anchors. A unique nonpartial A/B pair is closely linked at counts up to four and separated above four. Alternative cutoffs are 2, 4, 6 and 10. Multiple supported A or B candidates yield a complex architecture. Conflicting A/B functions on one protein, missing supported partners or unresolved circular path counts yield unresolved status.

Distances include nonnegative edge gap, actual overlapping bases, midpoint distance, CDS-order count, relative orientation and normalized position. The number of CDS wholly contained in the physical gap is preserved separately as `complete_gap_cds`. Genome wrapping is allowed only when the frozen GenBank record explicitly says circular. Circular permutation by itself does not trigger wrapping. Circular order counts use CDS midpoint loci along the selected shortest edge arc, with compound locations and tied paths retained. If tied order counts differ, no arbitrary classification is forced. Nearby supported holins are counted within five CDS indices of either anchor. The nearest product explicitly containing capsid or tail is reported as an annotation proxy, not a validated structural module.

## Families, neighborhoods and background comparison

MMseqs2 `easy-cluster` constructs study-specific protein families at identities 0.30, 0.40 and 0.50, with coverage 0.80, coverage mode 0, sequence-identity mode 0, alignment mode 3, cluster mode 0, k-mer length 5, single-step clustering and E-value 0.001. The primary identity is 0.40. These settings use explicit aligned-residue identity on representative-member edges rather than an inferred score-based identity. They are not an exhaustive pairwise search or a guarantee of the same minimum identity between every pair within a family. Cluster output must assign every searchable protein exactly once. Family identifiers hash sorted unique member-sequence hashes, making identifiers stable against representative choice within a fixed membership set. Adding a distinct sequence can change that family identifier.

Neighborhoods contain up to 3, 5 or 10 CDS on each side, with five primary. They are oriented to the anchor strand, preserve relative gene orientation, stop at linear boundaries and exclude the anchor. Unclustered neighbors receive unique identifiers, preventing false similarity from a shared missing label.

Jaccard similarity is shared family-set size divided by union size. The order-sensitive supplementary metric is twice the longest common subsequence length divided by the total token count. Each token includes family, side of anchor and relative strand. Empty comparisons are unavailable, not zero.

Each genome pair must share a usable cluster, have unique supported LysB anchors in the same single-copy family and resolved architecture, and belong to different near-duplicate screening groups. Comparisons use homologous non-lysis control anchors in those same genomes. Controls are single-copy, exclude every family containing any lysis-associated evidence, exactly match oriented boundary completeness and, for linear records, nearest-terminus position bin, lie within a factor of two of both target protein lengths and differ in family prevalence by at most 0.20. Circular origins do not receive the terminus-position matching rule. Covariate distance orders controls; conservation scores never select them. At most 20 are retained and at least five are required.

The pair contrast is LysB-neighborhood similarity minus the matched-control mean. Controls are background measurements, not independent biological observations. All eligible and untestable comparison rows are preserved across thresholds, windows, confidence scopes and representative subsets.

## Inference and validation

The primary H2 comparison is separated architectures, high/moderate evidence, all nonduplicate eligible pairs, 0.40 family identity, five-gene windows and Jaccard similarity. Pair contrasts are averaged within each cluster, then clusters receive equal weight. Inference requires at least five contributing clusters and additional independence and sign-symmetry assumptions. A two-sided sign-flip test enumerates all signs through 20 nonzero cluster contrasts; larger sets use 9,999 Monte Carlo draws with plus-one correction. A 5,000-replicate percentile bootstrap resamples whole cluster effects for a 95% interval. [Assumptions and multiplicity](statistical_assumptions.md).

H1 architecture frequencies and H4 identification uncertainty are descriptive. H3 recurrent reorganization is explicitly untestable without adequate histories. No statistical association is presented as proof of an evolutionary mechanism.

Validation audits frozen input checksums and published architecture controls. A control can pass only with independently supported functional anchors and a curated expectation; annotation-only recovery is reported separately. Missing or unresolved controls produce incomplete validation rather than an invented pass. Candidate ranking is lexicographic by confidence, partial-call count, representative status, intervening CDS, base-pair gap and accession. A ranking is not a novelty or mechanistic result.

A separate diagnostic examines the three exact Yvonnetastic proteins selected from the published-control record. Biopython PairwiseAligner uses local BLOSUM62, gap open -10 and extension -0.5 against same-category experimental references. Identity divides exact residue matches by all local alignment columns including gaps; coverage divides consumed residues by full query or target length. Raw scores are uncalibrated, have no E-values and cannot alter any functional evidence, architecture or H2 test.

The numbered runner stops on raised errors, writes stage-output checksums and an execution report, and checks recorded dependencies when resuming. Receipts bind the scientific configuration and relevant module, shared-code, runner and curated-reference source hashes. Rerunning a stage invalidates that stage's later receipts. Frozen cohort reuse must match the requested deterministic selection, and a conflicting version-specific GenBank annotation is not silently overwritten. Resource values come from execution reports. A successful process exit does not override an incomplete biological-control status. Byte-identical reproducibility must be measured by rerunning and comparing outputs; it is not presumed.
