# Component and control-availability amendment

Design recorded on 2026-10-17, before the amendment-feasibility program reads conservation outcomes from either amended reference panel. This is a secondary analysis informed by the original pilot's identification and matching limitations. It is not a preregistration made before the original pilot. Existing primary architecture categories, matching criteria, minimum five controls and minimum five cluster effects remain unchanged.

## Eligibility based on all detected components

The secondary unit is one complete, independently supported Lysin B protein and the entire set of complete, independently supported Lysin A proteins detected in its genome. An eligible call has high or moderate confidence, an explicit reference identifier, a non-contextual experimental, homology, alignment or HMM evidence source, and traceable reference provenance. All eligible A components are retained. No single A component is selected to make a genome qualify. Multiple functional domains on one protein do not create additional protein components. A protein with conflicting supported A and B assignments makes the secondary architecture unresolved. Multiple supported B proteins also make it unresolved.

All A-B pairs are measured with the existing architecture coordinate method, including CDS order, strands, overlaps, boundaries, topology and circular-path ambiguity. All component details and pair measurements are exported. Primary `complex` classifications are retained in a separate column. This amendment does not assert that two detected A proteins form an experimentally established split enzyme or that every biological A component has been detected.

For each configured separation threshold, the secondary category is `all_detected_components_distal` when every detected A-B distance exceeds the threshold, `all_detected_components_linked` when none exceeds it, and `mixed_detected_components` otherwise. Missing A or B support, partial supported components, ambiguous distances and conflicting or multiple B calls remain unresolved with explicit reasons. The high-confidence sensitivity recomputes the component set; removal of a moderate call is recorded and is not interpreted as evidence of gene absence.

## Availability funnel

For every family-identity and neighborhood-window setting, the program enumerates all within-cluster genome pairs. It records unique independently supported homologous B anchors, resolved A architecture, separated architecture, exclusion of a shared near-identical similarity group, complete target flanks, and the sequential availability of single-copy homologous nonlysis controls after boundary, position, protein-length and prevalence matching. Counts are computed for both the unchanged primary architecture rule and the secondary all-components rule, and for high/moderate and high-only evidence.

Complete target flanks are a diagnostic, not a new eligibility requirement: the existing method permits clipped flanks when controls match the same completeness. The complete-flank count is therefore a branch of the funnel, not a mandatory filter. Control filters retain their original definitions: exact oriented completeness, exact nearest-terminus bin in linear genomes, protein-length ratios between 0.5 and 2, family-prevalence difference at most 0.20, and at least five controls. Circular origins do not determine a position bin. No conservation score is read or used to select controls, define components, or choose a favorable configuration.

Pair and control counts describe feasibility in the observed cohort. They are not a population power calculation, evidence of function, or proof that named clusters are independent evolutionary replicates. Shared controls do not increase biological replication. For a two-sided exact cluster sign-flip test, five nonzero cluster effects have a minimum attainable p value of 2/32 = 0.0625; at least six are needed even to permit p below 0.05. This arithmetic does not change the primary five-cluster gate or establish adequate power. Discovery of previously undetected proteins can change eligibility and must be reported rather than assumed.

## Output isolation

`scripts/amendment_feasibility.py --root INPUT_ROOT --out NEW_OUTPUT_DIRECTORY` reads processed genomes, CDS, functional evidence, primary architectures, family memberships and configuration. It writes component calls, component-pair distances, pair-level feasibility, sequential control counts, aggregate funnels and a provenance report only beneath the explicit output directory. It neither replaces primary outputs nor reads neighborhood-conservation results. Each input checksum and all output paths are recorded. The program rejects an output directory that would overwrite its scientific inputs or the original result-table directory.
